# CodeAlpha_StockPortfolioTracker

**CodeAlpha Python Programming Internship — Task 2**

A simple stock tracker that calculates total investment value based on
manually defined (hardcoded) stock prices.

## How to run
```bash
python stock_tracker.py
```

## Features
- Hardcoded dictionary of stock prices (AAPL, TSLA, GOOGL, MSFT, AMZN, META, NFLX)
- User inputs stock symbol + quantity, repeated until 'done'
- Calculates per-stock value and total portfolio investment
- Optionally saves the summary to a `.txt` or `.csv` file

## Concepts used
Dictionaries, input/output, basic arithmetic, file handling (`csv` module).
